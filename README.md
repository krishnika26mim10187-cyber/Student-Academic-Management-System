
# Student Academic Management System

## Overview

The Student Academic Management System is a Python-based command-line application designed to manage student academic information.

## Features

- Add and manage student details
- Calculate marks, percentage and grade
- Track student attendance
- Generate student academic reports
- Input validation and error handling

## Technologies Used

- Python
- Object-Oriented Programming
- Lists and Dictionaries
- Functions and Modules

## Project Modules

1. Student Management
2. Marks and Grade Management
3. Attendance Management
4. Report Generation

## How to Run

Run the following command:

python main.py

## Testing

The project was tested for:

- Valid student information
- Marks calculation
- Invalid marks
- Attendance calculation
- Invalid attendance
- Student report generation
