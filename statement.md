
# Student Academic Management System

## Problem Statement
Managing student academic information manually can be time-consuming and may lead to errors while maintaining student details, marks, grades, and attendance. This project provides a simple Python-based system to manage student academic information.

## Scope
The system manages student details, marks, grades, attendance, and generates academic reports.

## Target Users
Students, teachers, and academic staff.

## High-Level Features
- Add, view, search, update, and delete student details
- Enter and calculate marks, percentage, and grade
- Record and calculate attendance
- Generate student academic reports
